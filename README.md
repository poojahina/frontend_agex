# Amplifier for Agentic AI

Complete React + TypeScript frontend demo for an enterprise agentic AI orchestration platform.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The app uses deterministic mock data and localStorage persistence for demo workflows and custom agents.
- No backend is required for the initial demonstration.
- Integration settings are placeholders and do not store production credentials.
